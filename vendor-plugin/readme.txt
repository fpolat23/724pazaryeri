=== PazarYeri Vendor System ===
Contributors: 724pazaryeri
Tags: woocommerce, vendor, multivendor, marketplace
Requires PHP: 7.2
Requires at least: 5.6
Stable tag: 1.0.0

Hafif WooCommerce çoklu satıcı sistemi. Dokan alternatifi.

== Özellikler ==
* Vendor rolü ve frontend dashboard (/saticim/)
* Kategori bazlı komisyon (her kategoriye ayrı oran)
* Satıcı bazlı komisyon override
* Sipariş tamamlanınca otomatik komisyon hesaplama
* Bekleyen ödemeler ekranı + manuel "Ödendi" işaretleme
* Vendor sadece kendi ürünleri ve siparişlerini görür
* Sipariş yönetimi: kargo firması, takip no, müşteriye not
* Satıcı başvurusunu tek tıkla onaylama

== Faz 1 (1.0.0) ==
* Temel vendor sistemi
* Komisyon motoru
* Frontend dashboard
